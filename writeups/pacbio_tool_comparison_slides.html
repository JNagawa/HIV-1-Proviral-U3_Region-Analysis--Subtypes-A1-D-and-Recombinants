extract_provirus_strip_hostN (bash / awk / seqkit)

What was done & why

  • SMRTcap reads carry host flanks masked with N; the integrated provirus is the ACGT core.
  • Strip the leading & trailing N-runs to recover the proviral core; internal bases preserved so a stray internal N never truncates the genome.
  • Path A (input already masked); per-read start/end coordinates logged. Custom bash/awk/seqkit — no Python.

Step 2 · Genome Assembly

Challenges & resolutions

hifiasm (de novo comparator) not yet installed on the node
The assembly step auto-skips hifiasm rather than failing. hifiasm is pinned in the env file and installs in the pending env-setup; its comparison row is added on re-run — no rework of the minimap2 side.
Reference-guided consensus masks missing coverage
bcftools consensus returns HXB2-length output, filling gaps with reference bases where partial reads don't reach. Reported as a caveat; U3-region read depth is checked per sample so reference-fill isn't mistaken for real signal.

Step 3 · Multiple Sequence Alignment

Tools, configuration & results

MAFFT (L-INS-i)MUSCLEClustal Omega

What was done & why

  • Aligned HXB2 + the 4 sample consensus with each tool (reuses the Illumina arm's run scripts — alignment is platform-agnostic).
  • MAFFT as L-INS-i (--localpair --maxiterate 1000).
  • All three retained 5/5; MAFFT fastest (78 s vs 119 s MUSCLE, 201 s Clustal Ω).
Coloured U3 alignment (MAFFT L-INS-i): HXB2 + 4 PacBio consensus, 453 columns; top band = per-column conservation (grey dips = sample variation).
Finding

MAFFT L-INS-i is the pick — most accurate for divergent HIV and fastest here. Unlike the Illumina U3, the PacBio consensus set shows real inter-sample variation where reads covered.

Step 4 · Biological Filtering & Intactness

Challenges & resolutions

HIVSeqinR needs a manual protocol-specific primer configuration
It refuses to run until 2nd-round PCR primers are supplied and .CONFIGURED is set. Documented the exact step; HIVIntact + Poplars give interim intactness/hypermutation signal meanwhile.
HIVIntact heuristics are subtype-B optimised — bias risk on A1/D
Its calls can be skewed for this cohort. Flagged interpret-with-caution; HIVSeqinR is the A1/D-validated primary once configured.
